NEIS API 키가 아직 없나요?
  1. 나이스 교육정보 개방 포털에서 로그인합니다.
  2. 활용가이드 → 인증키 신청을 선택합니다.
  3. 발급된 키를 마이페이지에서 복사하고 암호 관리자 등 보안이 철저한 곳에 별도로 보관합니다.
  4. 아래 입력란에 붙여넣고 학교를 검색합니다.
별도 회원가입 없이 구글·네이버·다음 계정 인증으로 로그인할 수 있으며, 공식 안내상 인증키는 신청 즉시 발급됩니다. API 키가 포함된 메모나 백업 파일은 다른 사람에게 공유하지 마세요.
